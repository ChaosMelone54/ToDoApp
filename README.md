# To Do App
This To Do App is a web based app, means it runs in your browser. It runs on every device from mobile devices to desktop PCs that support Java Script in the browser.
Your tasks will be saved automaticaly after adding them to your list. You can create multiple task lists for different purposes and also delete lists, when you don*t need the lists anymore. For anyone who needs
the lists on other devices there is a built-in export function which can be used to export lists and also import them on other devices.
## Installation
There is no need to compile this programm, just clone the repository with the following command: git clone https://github.com/ChaosMelone54/ToDoApp.git
After cloning find and open the index.html file.
